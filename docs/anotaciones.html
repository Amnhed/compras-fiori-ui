uicompras/annotations.cds declara la pantalla. El servicio que corre las publica en el metadata.

Conexión Proxy Lista Registro Anotaciones

Este archivo vive en el frontend, pero cds watch no lo compila. La copia que viaja en GET $metadata es compras-empresariales-cap/srv/compras-ui.cds. Las dos dicen lo mismo, para que la UI y el servicio no se desalineen.

Antes la lista pedía proveedor y total. Esos campos no existen en el modelo. Ahora apunta a folio, estado, importeTotal y createdAt.

UI.LineItem : [
    { Value : folio, Label : 'Folio' },
    { Value : estado, Label : 'Estado' },
    { Value : importeTotal, Label : 'Importe total' },
    { Value : createdAt, Label : 'Fecha creación' }
],
UI.Facets : [
    { Label : 'Datos generales', Target : '@UI.FieldGroup#Cabecera' },
    { Label : 'Artículos', Target : 'posiciones/@UI.LineItem' }
]

UI.FieldGroup#Cabecera es el formulario del folio. posiciones/@UI.LineItem es la tabla de artículos del registro. UI.DataFieldForAction coloca Aprobar y Rechazar. @Common.FieldControl: #ReadOnly impide editar estado e importe en la object page.
