Cómo se engancha Fiori

Esta UI no guarda órdenes. Pide OData al backend y pinta lo que dicen las anotaciones.

Conexión Proxy Lista Registro Anotaciones
List Report y Object Page → proxy /odata → localhost:4004 ComprasService

El proyecto uicompras es una plantilla Fiori Elements. Las rutas de webapp/manifest.json apuntan a /OrdenesCompra. No hay un controlador que pinte la tabla a mano: sap.fe.templates.ListReport y ObjectPage leen $metadata.

Para verlo hacen falta los dos procesos: cds watch en compras-empresariales-cap y npm start dentro de uicompras. El navegador pide usuario y contraseña del mock (alice/alice o bob/bob) porque el OData ya no es anónimo.

La arquitectura del servicio, el CRUD y los roles están en compras-empresariales-cap/docs.
