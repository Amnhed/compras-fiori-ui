Lista

La primera pantalla es un List Report de OrdenesCompra.

Conexión Proxy Lista Registro Anotaciones

El manifest declara la ruta vacía hacia sap.fe.templates.ListReport con contextPath: /OrdenesCompra. Al abrir, Fiori hace un GET /odata/v4/compras/$metadata y después un GET /odata/v4/compras/OrdenesCompra.

Las columnas no están en un XML de vista. Salen de UI.LineItem: folio, estado, importe total y fecha de creación. Los filtros de la barra son UI.SelectionFields: folio y estado. importeTotal no se filtra en la base porque es virtual; el backend lo calcula en el after READ.

En cada fila pueden aparecer Aprobar y Rechazar. El servicio solo los concede al rol Aprobador, así que con alice el backend responde 403 si se invocan, y con bob sí cambian una orden retenida.

"targets": {
  "OrdenesCompraList": {
    "name": "sap.fe.templates.ListReport",
    "options": {
      "settings": { "contextPath": "/OrdenesCompra" }
    }
  }
}
