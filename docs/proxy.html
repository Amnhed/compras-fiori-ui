Proxy

Archivo uicompras/ui5.yaml. El navegador habla con el servidor de Fiori; ese servidor reenvía /odata.

Conexión Proxy Lista Registro Anotaciones 
backend:
  - path: /odata
    url: http://localhost:4004

En manifest.json el data source usa la ruta relativa /odata/v4/compras/. Gracias al proxy, esa ruta sale del puerto de la UI y llega al CAP que escucha en el 4004. Las librerías UI5 (/resources) no van al backend: salen de https://ui5.sap.com.

Si el backend está apagado, la lista no tiene metadata y la pantalla no arma columnas. El proxy no transforma el JSON: solo cambia el host.
